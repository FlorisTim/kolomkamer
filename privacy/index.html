Privacy Policy: Kolomkamers

Last updated: August 31, 2026

Information kolomkamers collect

Kolomkamers saves the passwords and usernames you give it, to ensure your account is functional. passwords are hashed with Argon2
Kolomkamers also stores your ip address for up to 31 days.
When you register with an Email this will also be stored like usernames are.

Kolomkamers stores the data given when you use any objects in the web builder that use auth tokens or playlist ID's.
These tokens are stored seperate from passwords and usernames to ensure security.
Specifically for when other people view pages using these objects, to fetch and load the contents the token must be used.
What the token has access to depends on how the object is coded (these can be made by any person) but the objects provided with the base editor will use them only to fetch playlist or grab songs, basically read, not write.

When sharing a token, consider it public it will only be used by my server but it will get used everytime someone enters your page(s). Make sure to set the right permissions on your tokens.
Everything between the server and client is communicated over https.

Tokens, Passwords, Usernames and ip addresses are removed on request, as someone who values privacy i made it the first option on your user profile

What does kolomkamers do?

Its a web-builder type website, based on the creators websites (@isomeone).
You have a singular column, where you can drag and drop elements in, and change the style.

Every user gets a base of 100kb to work with, big files like images, music or videos are expected to be hosted somewhere else.

Some tokens are provided, like the youtube playlist token access, do not rely on it, best to get your own token, but for people making a simple personal page its fine to use
